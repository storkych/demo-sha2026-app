# Архив рейсов

Авиационный квест: три комнаты, девять загадок, архив и двухчасовой таймер.

Веб-версия: https://demosha2026.storkyproduct.ru. Сборки для Windows и macOS публикуются вместе в GitHub Releases по тегам `vX.Y.Z`, после успешных проверок обеих платформ. Push в `main` запускает проверки и автоматическую выкладку сайта. Подробности: [ops/README.md](ops/README.md).

## Запуск

- Windows x64: скачайте `FlightArchive-Portable-<версия>.exe` из GitHub Releases. Скопируйте в отдельную папку с правом записи и запустите. Установка и интернет не нужны.
- macOS: скачайте `FlightArchive-macOS-<версия>-universal.dmg` и перенесите **Flight Archive** в **Applications**. Один файл подходит для Intel и Apple Silicon. Также публикуется ZIP с приложением. После скачивания интернет не нужен.
- Прогресс Windows: `quest-progress.json` рядом с EXE. Служебные данные Electron: папка `FlightArchiveData` рядом с EXE. Для переноса текущей игры копируйте всю папку.
- Прогресс macOS: `~/Library/Application Support/FlightArchive/quest-progress.json`; служебные данные — вложенная папка `FlightArchiveData`. Обновление приложения не удаляет прогресс.
- macOS-сборка подписана локально (ad-hoc), без Apple Developer ID и нотарификации. При блокировке первого запуска разрешите его через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
- Веб: содержимое `dist` можно разместить на статическом хостинге. Прогресс сохраняется в браузере, независимо от других устройств.

## Тестовые данные

- Вход без пароля: кнопка «Войти в систему» сразу запускает вступительное видео.
- Ответы загадок заданы в `src/engine.mjs`.
- Пароль отмены: `Игнатий Даванков`. Поле видно рядом с таймером, ввод доступен после завершения всех трёх разделов. Символы не скрываются.
- Панель прогресса: наберите `ТЧша2026` с клавиатуры в любом экране. Вставка из буфера не является набором. Панель содержит девять галочек и сброс игры, без редактора контента и времени.
- Вступление и финальный репортаж включены в сборку: `public/media/intro.mp4` и `public/media/outro.mp4`.

Таймер запускается по окончании видео, ещё до нажатия Enter. Время идёт при закрытом приложении. После истечения текущая игра блокируется; физические файлы на компьютере не удаляются. Сброс в панели ведущего начинает новую игру.

## Разработка

`npm install`, затем `npm run dev`.

- `npm test` — проверки правил игры.
- `npm run build` — проверка TypeScript и веб-сборка.
- `npm run desktop` — локальный запуск Electron.
- `npm run pack` — portable Windows x64 на Windows, универсальные DMG и ZIP на macOS.
- `npm run pack:mac` — универсальные DMG и ZIP (запускать на Mac).
- `npm run test:browser` — полный браузерный проход (при запущенном `npm run dev`, нужен Google Chrome).
- `npm run test:desktop` — проверка запуска Electron, сохранения и восстановления прогресса (после `npm run build`). Для проверки упакованного приложения задайте `TEST_PACKAGED=1`.
- `node tests/macos.mjs` — в чистом macOS CI: обе архитектуры в ZIP, подпись, запуск с DMG только для чтения и восстановление прогресса из ZIP.

Релизный workflow собирает Windows и macOS параллельно, проверяет установочные файлы и публикует EXE, DMG, ZIP и общий `SHA256SUMS.txt` одним этапом. Для нового релиза обновите версию в `package.json` и `package-lock.json`, затем запушьте соответствующий тег `vX.Y.Z`.

Вложенность архива: одна корневая папка → три авиакомпании → по три направления → по три файла с названиями рейсов. Каждый завершённый раздел открывает одну ступень доступа. Три сегмента у каждой вкладки показывают решённые загадки; у финальной вкладки — уровни доступа.

Приложение рассчитано на современные Windows x64 и macOS (Intel / Apple Silicon). Сборки не подписаны коммерческими сертификатами. Системное время и локальные файлы считаются доверенными: это приложение для ведущего квеста, а не защищённая от вмешательства платформа.

## Каталоги финального блока

| Авиакомпания | Западное направление | Северное направление | Южное направление |
| --- | --- | --- | --- |
| поражение | COF, YAB, ESS | KON, STA, NTI | ISA, BEL, LAA |
| сибирские авиалинии | VAS, ILI, YKK | MAT, VEI, KOG | TAT, IAN, ASE |
| D6 airlines | FED, ORB, ESS | VLA, DLE, NKO | IGN, ATI, YDA |

Вступительное и финальное видео занимают весь экран приложения и воспроизводятся без элементов плеера. После окончания доступны «Продолжить» (или Enter) и до трёх повторов каждого видео. Число повторов сохраняется в прогрессе; повтор вступления не перезапускает таймер.
