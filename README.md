# Архив рейсов

Авиационный квест: три комнаты, девять загадок, архив и двухчасовой таймер.

Веб-версия: https://demosha2026.storkyproduct.ru. Portable-сборки публикуются в GitHub Releases по тегам `vX.Y.Z`. Push в `main` запускает проверки и автоматическую выкладку сайта. Подробности: [ops/README.md](ops/README.md).

## Запуск

- Windows: `release/FlightArchive-Portable-1.0.0.exe`. Скопируйте в отдельную папку с правом записи и запустите. Установка и интернет не нужны.
- Прогресс: `quest-progress.json` рядом с EXE. Служебные данные Electron: папка `FlightArchiveData` рядом с EXE. Для переноса текущей игры копируйте всю папку.
- Веб: содержимое `dist` можно разместить на статическом хостинге. Прогресс сохраняется в браузере, независимо от других устройств.

## Тестовые данные

- Пароль входа: `1111`.
- Ответ на каждую загадку: `1111` (подписан в окне).
- Код отмены: `SHA-2026` (подписан у таймера). Файл находится в «Архив → Горизонт → Реестр 02».
- Панель прогресса: наберите `ТЧша2026` с клавиатуры в любом экране. Вставка из буфера не является набором. Панель содержит девять галочек и сброс игры, без редактора контента и времени.
- Пока видео не предоставлено, используется восьмисекундная демонстрационная заставка. Настоящее видео можно добавить при разработке как `public/media/intro.mp4` и пересобрать приложение.

Таймер запускается по окончании видео, ещё до нажатия Enter. Время идёт при закрытом приложении. После истечения текущая игра блокируется; физические файлы на компьютере не удаляются. Сброс в панели ведущего начинает новую игру.

## Разработка

`npm install`, затем `npm run dev`.

- `npm test` — проверки правил игры.
- `npm run build` — проверка TypeScript и веб-сборка.
- `npm run desktop` — локальный запуск Electron.
- `npm run pack` — portable Windows x64.
- `npm run test:browser` — полный браузерный проход (при запущенном `npm run dev`, нужен Google Chrome).
- `npm run test:desktop` — проверка запуска Electron и сохранения рядом с приложением (после `npm run build`).

Вложенность архива: одна корневая папка → три авиакомпании → по три реестра → по три файла с названиями рейсов. Каждый завершённый раздел открывает одну ступень доступа. Три сегмента у каждой вкладки показывают решённые загадки; у финальной вкладки — уровни доступа.

Приложение рассчитано на современные Windows x64. Сборка не подписана коммерческим сертификатом. Системное время и локальные файлы считаются доверенными: это приложение для ведущего квеста, а не защищённая от вмешательства платформа.
